01코스 목적과 전체 구조

최종 목표는 수능 영어 지문을 제한 시간 안에 정확하게 읽고, 근거에 따라 문제를 해결하는 능력이다.

구문독해는 이를 가능하게 하는 기초 처리 능력이다. 단어 뜻을 아는 상태에서 출발해 핵심과 수식의 관계를 유지하며 영어 어순대로 의미를 누적하고, 표시와 도움 없이 새로운 문장·지문을 처리하도록 훈련한다.

기획 중심축
문장구조 기반 + 의미단위 처리 기반 + 내부 문법 태그 기반.
학생에게는 “무엇을 어떻게 읽는가”를, 교사에게는 “어디서 처리가 막히는가”를, 시스템에는 “다음에 어떤 문장을 배정할 것인가”를 제공한다.
대화에서 합의

유지할 설계 원칙

  • 공통 Scope & Sequence를 Band별로 반복·심화한다.
  • 학생이 먼저 끊고, 피드백 후 다시 처리한다.
  • 영어 어순에 따른 의미 누적을 완역보다 먼저 경험한다.
  • 새 문장과 지문으로 전이하고 마지막에는 표시를 제거한다.
  • 최종 교재는 시간 제한 수행을 포함하는 수능 실전편이다.
이번 문서의 구체화 제안

제작·검증 과정에서 확정

  • Band별 세부 단원 배치, 분량 및 권 구성.
  • 난이도 수치 범위와 콘텐츠 태깅 기준.
  • 숙달 판정, 복습 배정 및 시간 목표.
  • AI 피드백의 진단 규칙과 교사 검수 절차.
  • Band A~C 신규 샘플 및 모든 유사문장.

학습 단위의 확장

Band / 교재 가칭대상·성장 목표주요 학습 단위도착점
A · 문장 읽기 입문예비중~중1 · 발견짧은 문장 → 2~3문장 맥락핵심과 설명 덩어리를 구별해 읽는다.
B · 문장 확장과 연결중2~중3 · 독립 적용복합 문장 → 짧은 문단주절·수식절과 의미 관계를 스스로 처리한다.
C · 고등 복합구문과 지문고등 · 통합·자동화중첩 문장 → 완결 지문긴 구조를 처리하면서 주장·근거·대조 관계를 유지한다.
D · 수능 실전편수능 · 정확도와 시간의 통합지문 → 유형별 문제 → 실전 세트표시 없이 읽고, 근거를 찾아 제한 시간 내 판단한다.

학년은 권장 진입 구간이다. 실제 배치는 사전 진단과 영역별 숙달도에 따른다. Band C는 복합구문과 지문 이해의 안정화, Band D는 시험 과제와 시간 배분을 포함한 실전 수행에 초점을 둔다.

02Sentence Processing Framework

공통 처리 지도는 문장·텍스트·시험의 3개 층으로 구성한다. 아래 지도는 교육과정의 축이며, 매 문장을 학습하는 6단계 활동 흐름과 구분한다.

층위처리 기능학습자 행동관찰 증거
Layer 1
Sentence		CORE · 중심 찾기누가/무엇이, 무엇을 하는지와 필요한 목적어·보어를 찾는다.핵심절과 동사 선택
CHUNK · 의미 단위 묶기단어를 구·절 단위로 묶어 읽는다.경계 선택과 수정 기록
EXPAND · 확장 연결하기명사 뒤 설명을 연결하고 동사 뒤 필수 정보를 완성한다.수식 대상·동사 보충 정보 연결
CONNECT · 생각 연결하기절의 역할, 원인·대조·조건·비교 관계를 파악한다.절 범위와 의미 관계 판별
COMPRESS · 압축 풀기분사·생략·동격·병렬의 관계를 문맥 안에서 복원한다.행위 주체·병렬 범위 설명
INTEGRATE · 통합하기긴 수식과 절 내부 정보를 유지하며 전체 의미를 구성한다.핵심 명제 및 세부 관계 이해
Layer 2
Text		COHERE → ORGANIZE → INFER지시어·연결어를 추적하고, 주장·근거·예시를 조직하며, 문맥 근거로 추론한다.지시 대상, 문장 기능, 요지와 추론 근거
Layer 3
Test		LOCATE → JUDGE → PERFORM필요한 근거를 찾고 선택지를 판단하며 시간 안에 세트를 완수한다.정확도, 근거 타당성, 시간·미완료 항목

학생·교사·시스템의 3개 관점

학생에게 보여주는 언어

“명사 뒤 설명을 붙여 읽기”, “동사 뒤 의미 완성하기”, “긴 설명 뒤 중심으로 돌아오기”. 문법 용어는 필요할 때 ‘문법 더보기’로 제공한다.

교사와 시스템이 관리하는 정보

처리 기능, 문법·구문 태그, 중첩 및 의존 거리, 어휘 부담, 지문 기능, 도움 사용 이력. 동일 문법도 다른 처리 난도로 관리한다.

구조를 잠시 접어 보여줄 때는 핵심을 찾기 위한 임시 표시임을 분명히 한다. 예: “He believed something.”은 뼈대 안내이며, 실제 문장 이해에는 that절 내용과 because절 관계를 다시 통합해야 한다.

03Scope & Sequence · 공통 지도 × 4개 Band

기본 순서는 Core → Chunk → Expand → Connect → Compress → Integrate → Text이다. 기존 9개 Stage를 이 지도에 대응시키고, 마지막에 시험 수행 층을 확장한다. 각 Band에서 전체 지도를 다시 만나되, 초급에서는 압축·중첩 구조를 짧게 경험하고 상위 Band에서 본격적으로 다룬다.

Stage / 처리축A · 예비중~중1B · 중2~중3C · 고등D · 수능
1. 중심 찾기
CORE		짧은 주어·동사, 목적어·보어수식이 낀 주어와 주절 동사절·동명사 주어, 긴 목적어실전 문장의 핵심 명제 신속 파악
2. 의미 덩어리
CHUNK		시간·장소 전치사구, 기본 명사구길어진 구·절의 경계추상 명사구, 복합 전치사구표시 없이 의미 단위를 유지
3. 명사 확장
EXPAND		전치사구 후치수식, 짧은 관계절 맛보기관계절·분사·to부정사 후치수식다중 수식, 관계절 안의 수식수식 대상 추적, 핵심 복귀
4. 동사 확장
EXPAND		want to, ask someone to 등 친숙한 패턴동명사·to부정사, 목적격 보어, 지각·사역가목적어, 긴 보충어, 복합 보어추상 동사와 긴 목적어·보어 통합
5. 생각 연결
CONNECT		and, but, because, when, if명사절·부사절, 양보·조건·대조복합절, 접속 표현의 범위주장과 이유·양보 관계 신속 판단
6. 비교·관계
CONNECT		기본 비교급, 간단한 정도 표현as~as, more~than, so~that, too~to비교절 생략, 복합 비교·결과비교 기준과 논리 방향 유지
7. 압축 풀기
COMPRESS		기본 병렬과 반복 정보 생략 경험분사 수식 재방문, 짧은 동격·병렬분사구문·축약·삽입·생략·명사화압축 정보 복원, 병렬 범위 판단
8. 긴 문장 통합
INTEGRATE		핵심 + 설명 한 덩어리두 구조의 결합다중 중첩, 장거리 연결, 도치·강조·가정여러 구조의 동시 처리와 의미 유지
9. 지문 활용
TEXT		2~3문장, 대명사 지시와 내용 연결짧은 문단의 원인·대조·예시완결 지문의 논리·요지·추론문장 기능·지시·논리를 문제 근거로 활용
10. 시험 수행
TEST · 확장층		문장 의미 확인짧은 문단 이해 과제시간을 기록하는 지문·문제 적용유형별 적용 → 혼합 세트 → 시간 제한 실전

수능 실전편의 내부 순서

  1. 실전 진단:표시 없는 지문과 문제로 구조·어휘·논리·시간 병목을 구분한다.
  2. 문장 병목 보완:취약한 처리 기능에 한해 6단계 문장 훈련을 배정한다.
  3. 지문·유형 적용:요지·주장, 빈칸, 순서·삽입 등 과제별로 근거 탐색과 판단을 훈련한다.
  4. 혼합 세트:지문 간 시간 배분, 미해결 문항 재접근을 연습한다.
  5. 시간 제한 실전:학습 중 도움 없이 수행하고, 종료 후 오독 구간과 판단 근거를 복기한다.

실전에서는 매 문장마다 끊기 활동을 요구하지 않는다. 문장 훈련은 실전 수행 중 드러난 병목을 보완하는 경로로 사용한다. 시험 형식·문항 수·시간은 출시 시점의 공식 기준을 확인해 확정한다.

04난이도 체계

문법 항목이나 단어 수 하나로 레벨을 결정하지 않는다. 구조 종류·조합과 중첩을 먼저 보고, 연결 거리·어휘·의미·맥락 부담을 함께 검토한다. 문장 자체의 복잡도와 도움·시간 같은 과제 조건은 별도로 기록한다.

설계 축ABCD

콘텐츠 태깅의 운영 정의

  • Structure Count:한 문장에 나타난 목표 구조의 발생 수. 구조의 종류 수와 따로 기록한다.
  • Embedding Depth:주절을 0으로 두고 그 안에 포함된 절·비정형절을 내려갈 때 1씩 가산한다. 병렬 항목은 깊이를 늘리지 않는다. 전치사구 내부 확장은 별도 태그로 관리한다.
  • Dependency Distance:주어 핵심어–정형동사, 피수식어–수식부 시작점 등 연결 쌍을 지정하고 사이의 단어 수를 기록한다. 어떤 연결을 측정했는지 함께 보존한다.
  • Vocabulary:선정 어휘 목록의 수준과 실제 학습자의 미지어 비율을 함께 본다. 구조 진단용 문장에는 어려운 핵심 단어의 뜻을 선택 제공한다.
  • Task Conditions:힌트·번역·음성 노출, 시간 제한 유무를 문장 난도와 분리한다. 도움을 받은 성공과 독립 성공을 구별한다.

초기에는 각 축의 프로필로 난도를 관리한다. 단일 Sentence Complexity Score는 학습자 데이터와 전문가 평정을 확보한 후 가중치를 검증해 도입한다.

05공통 활동 흐름과 학습 UX

① 직접 끊기내 처리 방식 드러내기② AI 피드백관계 확인·재시도③ 구조 시각화뼈대와 확장 연결④ 직독직해어순대로 의미 누적⑤ 유사문장 적용새 문장에 전이⑥ 표시 제거 후 재독독립 읽기 확인
단계화면·학습자 행동피드백·기록
1. 직접 끊기표시 없는 원문을 읽고 단어 사이를 눌러 /를 넣거나 제거한다. 키보드로도 선택·해제한다.최초 분절, 수정, 제출까지의 활성 시간. 첫 화면에서 정답 경계를 노출하지 않는다.
2. AI 피드백문제가 의심되는 연결 한 곳을 확인하고 재시도한다.“왜 이 덩어리가 붙는가”를 설명한다. 경계 불일치만으로 오답 판정하지 않는다.
3. 구조 시각화주절 → 수식 → 절·병렬 관계를 단계적으로 펼친다.색뿐 아니라 괄호·연결선·텍스트 라벨을 함께 쓴다.
4. 직독직해영어 덩어리마다 의미를 예상하고 공개한다. 마지막에 전체 의미를 확인한다.앞의 의미를 유지하며 새 정보를 붙인다. 처음부터 자연스러운 완역을 제시하지 않는다.
5. 유사문장 적용어휘를 바꾼 문장 → 구조 위치를 바꾼 문장 → 짧은 맥락에 적용한다.힌트 없는 첫 시도의 관계 이해를 우선 측정한다.
6. 표시 제거 후 재독슬래시·색·괄호·번역을 제거하고 원문을 읽어 의미 질문에 답한다.의미 정확도와 활성 시간을 함께 기록한다. 후속 새 문장 및 지연 점검으로 숙달을 확인한다.
지문에서 다시 발견하는 활동의 위치
6단계 흐름을 유지하면서 ⑤의 확장 과제 또는 Unit 마무리에 배치한다. Band A는 짧은 맥락, B는 문단, C·D는 완결 지문으로 확장한다. ⑥은 원문 재독으로 마치고, 지문 활동을 한 경우 표시 없는 지문도 다시 읽는다.

한 Lesson의 구성 예시 분량 제안

대표 문장 1개를 6단계로 학습하고, ⑤에서 유사문장 2개를 적용한다. Unit 말미에는 새로운 문장과 지문으로 통합 점검한다. Band D의 실전 세트는 별도 무도움 모드로 운영한다. 학습 시간은 파일럿 결과로 정하며, 문장 재독 시간이 줄어든 것만으로 읽기 능력이 향상되었다고 판정하지 않는다.

06Band별 샘플 활동

아래 슬래시는 대표 분절 예시이며 유일한 정답이 아니다. 샘플 피드백은 예상 반응에 대한 설계 예시로, 실제 AI 실행 결과가 아니다. Band A~C와 유사문장·맥락 문장은 본 기획을 위해 작성했다. Band D 대표 문장은 사용자가 제공한 원문을 그대로 유지했다.

BAND A · 예비중~중1

명사 뒤에 붙은 짧은 설명을 읽는다

The girl with a red bag is my sister.

9단어 · CORE / CHUNK / EXPAND · 핵심: The girl is my sister. · with a red bag이 the girl을 설명

① 직접 끊기

미션: “누구를 말하는지, 어떤 설명이 붙었는지 생각하며 끊어 보세요.”

The girl / with a red bag / is my sister.

② AI 피드백

예상 반응: with를 앞 덩어리에 붙이고 a red bag만 따로 읽음.

“with a red bag은 어떤 소녀인지 알려 주는 표현이에요. 빨간 가방을 가진 사람은 누구인가요?” → the girl 선택 후 다시 끊기.

③ 구조 시각화
[The girl] ── [is my sister] └ 설명: with a red bag
④ 직독직해

그 소녀는 → 빨간 가방을 가진 → 내 여동생이다.

의미 누적: 소녀 → 빨간 가방을 가진 소녀 → 그 소녀는 내 여동생이다.

⑤ 유사문장 적용

The boy with a blue cap is my friend.

명사 뒤 설명 선택: with a blue cap → The boy.

I know the girl with a red bag.

설명이 목적어 안으로 이동: with a red bag → the girl.

맥락 확장: “Two girls are at the gate. The girl with a red bag is my sister.” → 어떤 소녀인지 구별하는 정보를 찾는다.

⑥ 표시 없이 재독

원문을 표시 없이 재제시한다. “가방을 가진 사람은 누구이며, 나와 어떤 관계인가요?”

확인 기준:소녀가 빨간 가방을 가졌으며 내 여자 형제라는 관계를 이해한다. sister를 언니·누나·여동생 중 어느 것으로 옮겼는지는 문맥 없이 오답 처리하지 않는다.

BAND B · 중2~중3

주어를 설명하는 관계절과 비교를 함께 처리한다

The book that my teacher recommended was more interesting than I expected.

12단어 · EXPAND / CONNECT / INTEGRATE · 관계절 + 비교절 · 핵심: The book was more interesting than I expected.

① 직접 끊기

미션: “책을 설명하는 부분과 그 책에 대한 판단을 나누어 읽어 보세요.”

The book / that my teacher recommended / was more interesting / than I expected.

② AI 피드백

예상 반응: recommended was를 같은 동사 덩어리로 묶음.

“recommended는 선생님이 책에 한 행동이고, was는 그 책이 어땠는지 이어 줍니다. that my teacher recommended가 설명하는 말을 찾아보세요.”

③ 구조 시각화
[The book] ── [was more interesting] └ that my teacher recommended → book 설명 └ than I expected → 비교 기준
④ 직독직해

그 책은 → 우리 선생님이 추천한 → 더 재미있었다 → 내가 예상했던 것보다.

누적 의미: 어떤 책인지 먼저 붙잡은 뒤, 재미의 정도를 나의 예상과 비교한다.

⑤ 유사문장 적용

The movie that my friend recommended was more exciting than I expected.

두 관계 선택: that절 → movie, than절 → 비교 기준.

I found a story that was more surprising than I expected.

구조 위치 변화: 비교 표현이 story를 설명하는 관계절 안에 들어간다.

맥락 확장: “I expected a simple story. The book that my teacher recommended was more interesting than I expected. I wanted to read it again.” → 기대와 실제 평가를 구별한다.

⑥ 표시 없이 재독

“누가 책을 추천했으며, 실제 재미는 예상과 어떻게 달랐나요?”

확인 기준:추천한 사람과 비교 방향을 모두 맞힌다. 관계절을 알아도 비교를 반대로 읽으면 CONNECT 보완 대상으로 기록한다.

BAND C · 고등

중첩된 설명을 지나 주절로 돌아오고 이유를 통합한다

The report written by researchers who studied online learning suggests that students need regular feedback because it helps them recognize mistakes.

21단어 · EXPAND / COMPRESS / CONNECT / INTEGRATE · 분사 수식 안의 관계절 + 내용절 + 이유절

① 직접 끊기

미션: “보고서의 설명을 읽은 뒤 중심 동사로 돌아오고, 보고서가 제시하는 내용을 연결하세요.”

The report / written by researchers / who studied online learning / suggests / that students need regular feedback / because it helps them recognize mistakes.

② AI 피드백

예상 반응: studied를 문장 전체의 중심 동사로 선택.

“who studied online learning은 researchers를 설명합니다. 보고서가 무엇을 말하는지 이어 주는 동사는 무엇인가요?” → suggests 선택. 다음으로 it이 가리키는 말 확인.

③ 구조 시각화
The report ── suggests [내용] └ written by researchers └ who studied online learning 내용: students need regular feedback └ 이유: because it helps them recognize mistakes it → regular feedback / them → students
④ 직독직해

그 보고서는 → 연구자들이 작성한 → 온라인 학습을 연구한 → 시사한다 → 학생들이 정기적인 피드백을 필요로 한다고 → 그것이 학생들이 실수를 알아차리도록 돕기 때문에.

통합 확인: 온라인 학습 연구자들이 쓴 보고서는, 피드백이 실수 인식을 돕는다는 이유로 학생들에게 정기적인 피드백이 필요하다고 시사한다.

⑤ 유사문장 적용

The guide written by teachers who work with beginners explains that short tasks build confidence because they give learners frequent chances to succeed.

명사–수식 연결을 복원하고 they → short tasks를 확인한다.

Students need regular feedback, according to a report written by researchers who studied online learning, because it helps them recognize mistakes.

출처가 삽입부로 이동해도 students need regular feedback을 유지한다.

맥락 확장: “Giving students access to lessons is only a first step. [대표 문장] Effective online courses therefore need more than a library of videos.” → 대표 문장이 결론에 제공하는 근거를 설명한다.

⑥ 표시 없이 재독

“보고서가 제시하는 필요와 그 이유는 무엇인가요? it은 무엇인가요?”

확인 기준:정기적 피드백의 필요, 실수 인식이라는 이유, it의 지시 대상을 함께 설명한다. 중첩 구조 인식과 담화 연결은 별도 기록한다.

BAND D · 수능

복합 구조를 통합해 주장과 이유를 읽는다

He believed that human societies were moving towards more rational forms regulated by effective and binding legal frameworks because only such frameworks enabled people to live in harmony, to prosper and to co-operate.

원문 유지 · 공백 기준 33단어(co-operate를 1단어로 계산) · 내용절 / 분사 후치수식 / 이유절 / enable + 목적어 + to부정사 / 병렬

① 직접 끊기

미션: “그가 믿은 내용, forms의 설명, because 이하의 이유와 세 가지 행동을 연결하며 읽으세요.”

He believed / that human societies were moving / towards more rational forms / regulated by effective and binding legal frameworks / because only such frameworks enabled people / to live in harmony, / to prosper / and to co-operate.

enabled people 뒤 경계는 다음 to부정사와의 관계를 유지하는 읽기상 분절이다. enabled people to live in harmony를 하나로 묶는 분절도 허용한다.

② AI 피드백

진단 예시 1: regulated를 societies의 새로운 중심 동사로 해석함.

“regulated by…는 more rational forms를 뒤에서 설명합니다. 사회가 어떻게 변화하고 있는지는 were moving이 나타냅니다. forms에 설명을 다시 연결해 보세요.”

진단 예시 2: 세 to부정사의 병렬 범위를 놓침.

“그러한 틀이 사람들이 가능하게 한 세 가지 행동을 찾아보세요. to live, to prosper, to co-operate는 enabled people 뒤에서 나란히 연결됩니다.”

③ 구조 시각화
He believed [믿음의 내용] └ that human societies were moving └ towards more rational forms └ regulated by effective and binding legal frameworks because [이유] └ only such frameworks enabled people ├ to live in harmony ├ to prosper └ to co-operate such frameworks → effective and binding legal frameworks

because절이 믿음 자체의 근거를 설명하는지, 그가 믿은 변화의 이유에 포함되는지는 앞뒤 문맥에 따라 읽힘이 달라질 수 있다. 단독 문장에서는 한 가지 부착 위치를 강제 채점하지 않고, 법적 틀의 역할이 이유로 제시된다는 관계를 확인한다.

④ 직독직해
  1. He believed → 그는 믿었다.
  2. that human societies were moving → 인간 사회가 나아가고 있다고.
  3. towards more rational forms → 더 합리적인 형태를 향해.
  4. regulated by effective and binding legal frameworks → 실효성 있고 구속력 있는 법적 틀에 의해 규율되는.
  5. because only such frameworks enabled people → 왜냐하면 오직 그러한 틀만이 사람들에게 가능하게 했기 때문에.
  6. to live in harmony → 조화롭게 살고,
  7. to prosper → 번영하며,
  8. and to co-operate → 협력하는 것을.

전체 의미: 그는 인간 사회가 실효성 있고 구속력 있는 법적 틀에 의해 규율되는 더 합리적인 형태로 나아가고 있다고 믿었다. 오직 그러한 틀만이 사람들이 조화롭게 살고 번영하며 협력할 수 있게 해 주었기 때문이다.

⑤ 유사문장 적용

She argued that local communities were moving towards more sustainable systems supported by shared resources because only such systems enabled residents to reduce waste, to save energy and to work together.

전이 1: supported by… → systems, such systems의 지시 대상, 세 to부정사의 병렬을 확인한다.

He believed that effective legal frameworks enabled people to build communities regulated by shared rules because such rules helped them resolve conflicts and cooperate.

전이 2: 분사 수식이 build의 목적어 communities 안으로 이동한다. 원문의 분절 위치를 외워서 적용할 수 없도록 설계한다.

지문 적용용 작성 맥락: “The thinker saw stable rules as a condition for social progress. [대표 문장] In this view, law was a means of making collective life possible.”

과제: 대표 문장은 앞의 견해를 어떻게 구체화하는가? → 법적 틀이 공동생활을 가능하게 하는 역할을 설명하고 그 이유를 제시한다. 이 맥락은 활동용 창작이며 원문 출처의 맥락이 아니다.

⑥ 표시 없이 재독

원문을 표시 없이 제시한 뒤 묻는다. “그가 믿은 사회 변화는 무엇이며, 법적 틀이 가능하게 한 세 가지는 무엇인가요?”

확인 기준:더 합리적 형태로의 변화, forms와 regulated의 관계, 조화로운 삶·번영·협력을 통합한다. 이후 새 지문·문제의 무도움 수행으로 실제 전이를 확인한다.

시간 운영:문장 재독은 개인의 첫 정확 읽기와 비교한다. 실전 숙달은 새 지문 세트에서 정확도와 시간 목표를 함께 충족하는지로 판단한다.

07평가·피드백·개인화

슬래시 일치율 대신 관계 이해를 평가한다

끊기는 처리 과정을 드러내는 도구다. 다른 위치에서 끊어도 주절·수식 대상·논리 관계를 유지하면 허용한다. 잘못된 분절이 의심되면 대상 연결이나 의미 질문으로 확인한 뒤 진단한다. 화면 클릭만으로 실제 인지 과정이나 시선의 되돌아읽기를 단정하지 않는다.

판정 축증거다음 학습
핵심·수식 관계주절 동사, 수식 대상, 절 범위를 선택같은 기능을 더 짧고 친숙한 문장으로 보완
의미 통합누가 무엇을 했는지, 이유·대조·비교 방향 설명어휘 지원 또는 관계 중심 직독직해 배정
독립 전이처음 보는 문장의 무힌트 첫 시도어휘·위치·조합 중 한 축을 바꿔 재점검
유지다음 학습일 이후 새 문장으로 지연 점검같은 처리 기능의 간격 복습
실전 수행새 지문 문제의 정확도·근거·활성 시간구조·어휘·논리·시간 중 병목에 맞춰 경로 분기

숙달 판정의 초안 파일럿 검증 필요

한 처리 기능에서 새 문장 5개 중 4개 이상을 도움 없이 정확하게 이해하고, 다음 학습일 이후 새 문장 점검에서도 관계 이해가 유지되면 다음 복잡도로 이동하는 방안을 검토한다. Band 이동은 여러 핵심 기능과 지문 과제를 함께 확인하며, Band D는 합의한 세트 시간 내 정확도를 추가 조건으로 둔다. 이 기준은 검증 전 운영 가설이다.

Sentence Processing Profile

CORE, 명사 수식, 동사 확장, 절 연결, 압축·병렬, 중첩 통합, 담화 관계별로 관찰 문항 수 / 무도움 성공 / 도움 후 성공 / 최근 확인일을 저장한다. 표본이 적을 때는 정확도 백분율만 크게 표시하지 않고 ‘추가 확인 필요’ 상태를 제공한다.

개인화 예시
중3 학생이 절 연결은 안정적이지만 긴 주어에서 주절 동사를 놓친다면, Band 전체를 낮추는 대신 명사 수식 문장의 어휘와 길이를 낮춘 보완 과제를 배정한다. 구조 이해가 회복되면 원래 지문의 표시 없는 읽기로 복귀한다.

AI 피드백의 역할과 품질 기준

  • 전문가가 검수한 구조·의미 관계와 허용 분절안을 기준으로 진단하고, AI는 학습자 반응에 맞게 설명을 조정한다.
  • 피드백은 “관찰한 부분 → 관계 설명 → 한 번의 재시도”로 짧게 구성한다. 근거 없는 칭찬이나 문법 용어 나열을 피한다.
  • 문맥에 따라 해석이 달라지는 문장은 허용 해석을 저장하고 단일 정답을 강제하지 않는다.
  • 슬래시만으로 확신할 수 없으면 확인 질문을 제공한다. 즉석 생성 문장은 구조·어휘·정답 검수 후 정규 코스에 편입한다.
